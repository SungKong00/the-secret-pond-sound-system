# 운영자 작업 흐름

| 사용 맥락 | 작업 | 시연 또는 화면 |
| --- | --- | --- |
| 관객과 운영자 | 운영자가 녹음을 열고, 전시 입력을 받아 Voice Stack에 반영 | 별도 Voice Stack 시나리오 |
| 리허설 운영자 | Mid EQ 열기 → 주파수 대역 조정 → Stable 적용 → 활성값 검토 | 대표 GIF. Low·Voice는 그대로 유지 |
| 리허설 운영자 | 개별 Voice Raw를 검토하고 채택한 녹음만 스택에 합치기 | README 기능표와 녹음 보관 설계 |
| 전시 운영자 | 소스와 입출력 장치 선택, 세 레이어의 믹스, 재생 중 EQ 조정 | 대시보드 정지 화면, Live 전환 화면, 현장 인프라 도식 |
