# Secret Pond 운영자 시연 설계

## 상황

관객 입장 전 리허설에서 운영자가 Mid 배경음이 두드러졌다고 판단했다. 출력은 잠시 꺼둔 채 다음 재생에 사용할 Mid 레이어의 특정 대역만 낮춘다. Low·Voice 설정은 그대로 둔다.

## 화면 순서

| 장면 | 운영자 행동 | 화면에서 확인할 것 |
| --- | --- | --- |
| 1. 시작 | 운영자 대시보드에서 Loop Mixer를 연다 | 실제 운영 UI, Stable 모드, 출력 꺼짐. |
| 2. EQ 편집 | Mid Graph EQ의 1 kHz 벨 밴드 점을 아래로 끌어 게인을 0 dB에서 −4 dB로 낮춘다 | 곡선에 완만한 골이 생기고 대역 값이 표시된다. |
| 3. 적용 대기 | 편집한 채로 잠시 확인한다 | ‘저장 안 된 오디오 변경’과 적용 대기. 아직 활성 설정이 아니다. |
| 4. 적용 완료 | ‘변경사항 적용 후 재생’을 누른 뒤 기다린다 | 적용 대기가 사라지고 편집한 EQ가 활성 설정에 남는다. 이 시연에서는 처음부터 끝까지 장치 출력이 꺼져 있다. |

## 촬영 기준

- 그래프·게인·적용 버튼을 한 화면에 둔다. 실제 대시보드와 로컬 FastAPI 오디오 렌더 경로를 사용한다.
- 리허설 데이터로 만든 Low·Mid WAV만 사용한다. 관객 녹음이나 현장 마이크·출력 장치는 사용하지 않는다.
- 브라우저 녹화에서 260프레임을 10.40초(25fps)로 내보냈다. EQ 드래그 구간에는 실제 브라우저 프레임이 약 39fps로 들어왔다. 적용 전후의 FastAPI 응답을 포함한 상세 정보는 QA 기록에 있다.
